隱私權政策

最後更新日期：2026 年 7 月 7 日

本隱私權政策說明「貨幣轉換器 Currency Converter」（以下簡稱「本擴充功能」）如何處理資料。本擴充功能的功能為：自動偵測網頁上顯示的各國貨幣金額（如 USD、EUR、JPY、TWD 等），並依即時匯率換算為使用者選擇的目標貨幣，顯示於原金額旁。

一、資料蒐集

本擴充功能不會蒐集、儲存或傳輸任何個人身分資訊，包括但不限於：姓名、電子郵件、帳號、瀏覽紀錄、網頁內容或輸入的文字。

網頁內容的讀取與金額換算完全在使用者的瀏覽器本機端執行，讀取的頁面文字不會被記錄，也不會傳送至任何伺服器。

二、本機儲存的資料

為提供功能，本擴充功能僅在瀏覽器內儲存以下設定資料（透過 chrome.storage）：

  • 使用者偏好設定：目標貨幣、是否啟用換算、是否顯示原始金額、是否顯示 $ 符號換算提示、使用者自訂的停用網站清單。此類設定經由 Chrome 同步儲存空間（storage.sync）保存，僅在使用者自己登入的 Chrome 帳號裝置間同步，開發者無法存取。
  • 匯率快取：為減少網路請求，向匯率服務取得的匯率資料會暫存於瀏覽器本機（storage.local）。

三、網路請求

本擴充功能唯一的對外網路請求，是向第三方匯率資料服務取得公開匯率資訊。該請求僅包含基準貨幣代碼（例如 USD），不包含任何個人資訊、瀏覽網址或網頁內容。

匯率資料來源：[匯率 API 服務名稱，ExchangeRate-API / Frankfurter]（該服務的隱私權政策）。

四、權限說明

本擴充功能要求的權限僅用於實現核心功能：

  • storage：於瀏覽器本機儲存使用者偏好設定與匯率快取。
  • 網頁內容存取（content script）：用於讀取頁面上顯示的金額文字並就地顯示換算結果。此處理僅發生在本機，不會上傳任何頁面內容。部分網站（如 AI 對話、程式碼平台）已預設排除以避免干擾。
  • [如 manifest 有 host_permissions，請列出，例如匯率 API 網域]：僅用於取得匯率資料。

五、第三方分享

本擴充功能不會將任何資料出售、交換或提供給第三方，亦不含任何廣告或追蹤程式碼（如 Google Analytics）。
